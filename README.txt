POLITY REVISION TRACKER

Files:
- index.html: page structure
- style.css: responsive styling
- app.js: tracker behavior and browser persistence

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html, or open it in Chrome/Edge/Firefox.
3. Tick lecture, revision and synopsis checkboxes; edit topic names, scores and review notes.
4. Data is saved automatically in localStorage in that browser on that device.
5. Use Export backup periodically to save a JSON backup. Import backup restores it.

Persistence note:
localStorage survives page reloads and browser restarts, but it is browser/device-specific.
Clearing browser site data, using private/incognito mode, or switching browser/device can remove
or hide the saved data. Export a backup for long-term safekeeping.
